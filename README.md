# Quota Pulse

一个不需要登录的桌面小弹窗，用来手动管理多个 Codex/GPT 账号的额度。

## 现在支持

- 两个账号分开管理，标签页切换
- 首次填写周额度、5 小时额度、窗口时长
- 手动同步“当前剩余”，自动计算本次减少了多少
- 一键标记“本轮 5 小时额度已用完”
- 5 小时额度自动倒计时并自动重置
- 周额度按 7 天周期自动重置，也支持手动重置
- 本地 JSON 持久化，不依赖登录，不接第三方接口

## 启动

```bash
npm install
npm start
```

## 使用方式

1. 打开应用后，先在每个账号页填写周额度和 5 小时额度，点击“保存配置”。
2. 如果你只是想走最简单模式：
   - 额度跑完时点击“本轮 5 小时已用完”
   - 应用会把当前 5 小时剩余额度从周额度里扣掉
   - 到达 5 小时时间点后，5 小时额度会自动恢复
3. 如果你在官方页面看到了更精确的剩余额度：
   - 直接在“手动同步”里填当前周剩余和当前 5 小时剩余
   - 应用会自动记录本次消耗了多少

## 数据位置

应用会把数据保存到 Electron 的 `userData/quota-state.json` 里。

## 当前假设

- 周额度以你第一次保存配置或手动重置周额度的时间为起点，按 7 天滚动重置
- 5 小时额度以你点击“用完”或手动同步到 0 的时间为起点，按设定小时数自动重置
